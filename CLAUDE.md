## Design Context

### Users
This app is for anyone interested in not wasting time. They are using it to make the passage of life feel concrete, so they can reflect on how much time has already passed and how much remains. The interface should create clarity and a sober sense that time is finite without becoming melodramatic.

### Brand Personality
Simple, minimal, geometric.

The tone should be direct, calm, and unsentimental. It should encourage reflection through restraint rather than spectacle.

### Aesthetic Direction
The visual direction should be minimal and geometric, with strong structure and clear spatial rhythm. Dark mode is the default presentation, but the system should be designed to support a light option as well.

The interface should avoid generic "AI dark mode" styling, decorative glow-heavy treatments, and cluttered card-heavy layouts. It should feel intentional, quiet, and precise.

### Design Principles
1. Make finiteness legible: the passage of time should be obvious at a glance.
2. Prefer restraint over decoration: every visual element should support reflection or comprehension.
3. Use geometric structure: grids, alignment, proportion, and spacing should do most of the visual work.
4. Support both dark and light themes, with dark as the default.
5. Treat accessibility as a worthwhile enhancement even if strict compliance is not a hard requirement.
